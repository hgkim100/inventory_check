모든 덧셈/뺄셈은 브라우저 계산기가 합니다. AI는 이미지에서 숫자만 읽고,
소계·현재고는 JavaScript 코드가 (전재고 + 입고 − 판매 − 반품) 공식으로 즉시 계산합니다.
숫자를 수정하면 모든 합계가 실시간으로 다시 계산됩니다.

🔑 API 키는 이 기기 브라우저(localStorage)에만 저장됩니다. 다른 사람이 같은 폰을 쓰면 같은 키가 사용되니, 분리하려면 ⚙️에서 "키 삭제"로 지우세요.
